# 手動スコア(グラウンドトゥルース)

人力で付けた過去試合のスコア記録。以下の用途に使う:

1. **評価データ**: 検出イベント(打席・打球・アウト等)の適合率・再現率の測定
2. **アラインメント**: スコアのイベント列は「順序付き」なので、動画から検出した
   候補イベント列との単調アラインメント(DTW的な対応付け)により、
   各打席・各プレーのタイムスタンプを推定できる
3. **語彙抽出**: キーワードスポッティング辞書(選手名・プレー用語)の元データ
